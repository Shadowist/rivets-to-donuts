Put together the router table, which took a bit. Had to drill new holes to mount it properly. Seems to sit nice and flat. It did take a bit to learn how to use it properly. As a kid, my dad had set up the router whenever we needed to use it.

After doing another round of sanding tweaks to get within the dimensional specification, it was time to get a 1/8” round over on the part. It had a slight bow to it, so I had to hold it down more than I’d like...especially with having my fingers so close to a sharp spinning piece of metal.

The only hitch was that it seems like I angled it slightly and had the router bit slightly high. Thus, a portion of the edge got chamfered instead of filleted. I think that’s still okay for manufacturing the part since I can just slide it along and form it with the other edges (it’s just a straight bend). I won’t be able to rely on that for more complicated form blocks though, so I better be more careful with the router position.
