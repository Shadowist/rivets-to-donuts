It’s not perfect by any means, but it should be usable. Some things I’ve found:

- Need to be EXTRA careful with the Olfa knife. It requires more pressure than you’d think in order to start that channel. Starting out, will need the guide a bunch. 
- Radius hole can be a bit bigger. Or I just need to taper and trim better.
- That spring back is REAL. From what I can tell, the angle is about 18 degrees off.
- A 12mm flange is tough to work with. I can make it happen, but it’s tricky.  20mm would be easier, but I’ll need a thicker form block to make that happen. 

Knowing all this now, I should be able to run through the rest of the ribs. At least the ones with straight cuts.

Update: OHHHHHH. I checked out the homebuilt help scratch build videos and saw that they had the rib actually on the table and the wood on top. That makes a LOT more sense.

While my part is pretty flat, it looks like I could’ve gotten much tighter fillets if I clamped it the other way. I’ll continue on and plan on redoing the first rib later.
