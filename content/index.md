Rivets to Donuts is an aircraft building blog by Steven Burrichter :) 

Part of the reason this blog exists is to meet the requirement where [51% of the aircraft must be built by an amateur](https://www.eaa.org/eaa/aircraft-building/builderresources/getting-started/selection-articles/~/media/68622b08072841d6b76c8cc7c3d51be0.ashx) in order to be issued an Experimental Amateur Built Airworthiness Certificate.

The other reason is to contribute my own findings to the home built community!
## Navigating the projects

Each project is separated by airplane model followed by an "overview" page. That page describes the project's goals and displays trackers for the various sections of the build. Then, there are subfolders for each section. The logs within each section are sorted by created date.

Probably the best way to peruse my build log: go to the overview note and look at the trackers. The tables there will have the actual recorded dates, hours logged, and a small description of each log.

### Maintenance Certifications
- Light-Sport Repairman (Inspection - Airplane)
- Rotax 912/914 iRMT (Service/Maintenace)

I took the Rotax courses years ago over at Motive Aero and had a good time. Well worth it if you haven't worked on aircraft engines before (or maybe legacy ones only).

The LSRI was a recent addition in order to be able to do the Condition Inspection on my Rans S-19 and save 8 hours of shop time for a typical event. After getting my operating limitations amended to allow Light Sport Repairmen to do Condition Inspections, I did my first full one in April! Without a helper, it took 13 hours...but I also felt a lot better knowing that I didn't miss a single thing.
